# Documentation and ledger conventions
<!-- role: contract | status: current 2026-09-04 | cited-by: CLAUDE.md -->

Repo-specific rules only; each names what enforces it. A rule with no command behind
it is an intention, not a convention. Enforcement is `python -m mdept.check`
(invariants I1 to I20), the Lean guards reached through `make lean`, and `tests/`. The
flow these rules serve is `docs/protocol.md`.

## Role line

Line 2 of every `docs/*.md` and every `proofs/*.md`:

```

```

Enforced by `python -m mdept.check`, which reads line 2 of both surfaces; I19 is the
strict case, requiring `role: record` on every `triage/MD_####.md`.

## One statement per entry, and IDs are permanent

One ledger entry states one thing. IDs are allocated once by `python -m mdept.new` and
never reused. Files are never deleted and never renamed: a duplicate becomes
`status: merged` with `merged_into` pointing at the survivor, and a restated theorem is
a new entry carrying `revises`. I2 checks uniqueness always and contiguity
`MD_0001..MD_N` across both repos in `--family` mode; I8 checks that every link
resolves, that no entry links to itself, and that nothing links to a `merged` entry.

## One ID form

`MD_0007`: underscore, four digits, everywhere. The ledger filename, the markdown
token, and the Lean namespace all use that one form, so a single grep finds every
mention of an entry. I1 checks filename against `id` and the `^MD_\d{4}$` regex; I12
checks that every `MD_####` and every `MDR:<stem>#C<n>` token in any markdown file
resolves.

## Settled statements are frozen

Once an entry is settled, its Statement and its Hypotheses do not change. A different
statement is a new ID with `revises`. I5 enforces the freeze mechanically: it compares
`statement_hash` against the sha256 of the audit's pretty-printed Lean type, so editing
a proven statement fails the check.

## Generated files are generated, never typed

| File | Regenerated by |
|---|---|
| `ledger/INDEX.md`, `ledger.json` | `python -m mdept.index` |
| `MathDept.lean` | `python scripts/gen_root.py --write` |
| `docs/MAP.md` | `repo-outline --write` |

`make regen` runs all three. `make check` regenerates each one in memory and fails on
any drift (I16), so a hand edit surfaces as a failed check rather than as silent
divergence.

## `sorry` fence

`sorry` appears only under `MathDept/Conjectures/`. `MathDept/Results/`,
`MathDept/Defs/` and `MathDept/Smoke.lean` are axiom-audited: their declarations use
only `propext`, `Classical.choice` and `Quot.sound`, plus per-declaration exceptions
listed in `audit/axiom-allowlist.txt` (one `<decl> <axiom>` line each). Three layers
enforce this: I20 and `python -m mdept.audit sorry` grep the token without needing
Lean, `tests/test_sorry_scope.py` runs that guard, and `scripts/AxiomAudit.lean` under
`make lean` catches `sorryAx` propagating out of a conjecture and `Lean.ofReduceBool`
arriving from `native_decide`.

## Lean file conventions

One file per entry, named for its ID, opening `namespace MathDept.MD_0007`. The
canonical declaration is `theorem statement`; a refutation adds
`theorem refuted : ¬ (...)` and lives in `Results/`, because a refutation is a result.
Imports are targeted (`import Mathlib.Data.Real.Basic`, not the whole library);
`import Mathlib` appears only in `MathDept/Smoke.lean`. `autoImplicit = false` is set
once in `lakefile.toml`. `python -m mdept.audit sorry` checks the namespace, the
`^MD_\d{4}$` stem, and that no stem lives in both `Conjectures/` and `Results/`;
`tests/test_root_fresh.py` checks that the generated root imports every module.

## Provenance is mandatory, and public provenance is abstract

Every non-`merged` entry carries `provenance.raised_by`. In this repo that field
carries `repo` plus a one-line neutral `domain`, and nothing else: `doc`, `anchor` and
the application text stay in the private request and triage record. `stipulated_by` and
`settled_by` (who, date, model) are public, because they are the credit trail. I3
enforces the closed key set and the closed enumerations for `status`, `kind`, `who` and
`how`; I7 resolves `raised_by` against the private side in `--family` mode.

## Trust tiers

Every bibliography entry declares a `Kind`: paper, book, notes, mathlib, forum, or
draft. `forum` and `draft` are never the `source` of a `cited` entry; they may inform
an entry and be named in its notes. I10 checks the tag, its Kind, and (privately) that
an extract exists; I11 keeps bibliography tags and extract filenames in sync.

## Prose

No em dashes. Use a period, a comma, a colon, or parentheses. I17 greps every markdown
file for U+2014 and fails on the first hit.

LaTeX is written to be readable as source, since most readers of this repo read the
markdown and not a renderer. State only the current state: an entry says what is known
now, and dated attempts live in the private `triage/` record.

## Commands

| Command | Runs | Use it |
|---|---|---|
| `make check` | `python -m mdept.check`, `python -m mdept.index --check`, `python -m mdept.audit sorry`, `python scripts/gen_root.py --check` | before every commit |
| `make regen` | `python scripts/gen_root.py --write`, `python -m mdept.index`, `repo-outline --write` | after adding or moving an entry, a Lean file, or a symbol |
| `make lean` | `python -m mdept.audit all --json --write audit/latest.json` | after any Lean change, to refresh what `--lean` reads |
| `make counterexamples` | `python -m mdept.refute --all` | to re-verify every witness |
| `make test` | `python -m pytest -v` | before a milestone commit |

`python -m mdept.check` also takes `--run-counterexamples`, `--lean` and `--family`. A
repo listed in `repos.yaml` that is absent fails the family check; it never skips.

## Which invariant enforces which rule

**Ledger shape.** I1 filename equals `id`, and the ID form; I2 IDs permanent, unique,
contiguous across both repos; I3 closed key set, closed enums, ISO dates; I4 status
matches its required evidence; I18 dates monotone, with `proven-informal` checked later
than settled.

**Evidence.** I5 formal pointer resolves and `statement_hash` freezes the statement; I6
counterexample artifact exists and verifies; I19 every `open` entry and every
non-citation settlement has a triage record; I20 `sorry` only under `Conjectures/`.

**Links and sources.** I7 `raised_by` resolves to a real doc and anchor; I8 links
resolve, no self-links, no links to `merged`; I9a a refuted entry is not implied by a
proven one; I10 `cited` sources are of a trusted Kind and have an extract; I11
bibliography tags and extract filenames stay in sync; I12 every `MD_####` and `MDR:`
token resolves.

**Flow.** I13 inbox lifecycle and Outcome completeness; I14 requests back-link to the
IDs they seeded; I15 consumer citations carry the right status word; I16 generated
views are fresh; I17 no U+2014 in prose.
