# MD_0101: one internal node fails at odd windows, two internal nodes pass everywhere
<!-- role: record | status: current 2026-10-25 | entry: MD_0101 -->

Informal proof attempt (S3). An attempt record, not a status. It proves the Statement of MD_0101 as written: part (a) by a case analysis on the four self-maps of $\{0,1\}$, which also proves the S1 reduction (the pass predicate of a one-node network depends on $(W,G)$ only through the classes $W = 1$, odd $W \ge 3$, even $W \ge 2$, and not on $G \ge 1$); part (b) by direct computation of the five runs of the witness for general $W, G \ge 1$; the four-nodes sentence as a corollary. No hypothesis was found missing. H2's $G \ge 1$ is used: at $G = 0$ the one-node table $z = 0$, $a = \mathrm{id}$, $b = \lnot$, $c = 1$ (notation below) passes at even $W$ (the odd-$W$ clause still holds at $G = 0$, by the enumeration below), so the case analysis below relies on $G \ge 1$ only in Step 3.

## Convention

A window of length $n \ge 1$ under a constant input $u$ starting from state $x_0$ applies $n$ updates $x_t = F(x_{t-1}, u)$, $t = 1, \dots, n$, and the readout is evaluated on $x_1, \dots, x_n$ (H3); $x_0$ is not read. The window ends in state $x_n$, which is the start state of the next window. The run of the protocol for training input $v$ is: start at $x^*$, a window of length $W$ under $v$, a window of length $G$ under $(0,0)$, a window of length $W$ under $(0,1)$ (H2: $T_1 = T_3 = W$, $T_2 = G$, all counted in updates). Inputs are held at the protocol's value throughout each window and are not updated by $F$ (H1). A trajectory evokes when the readout equals $1$ at some $t \in \{1, \dots, n\}$.

## Part (a): $k = 1$

The single internal node is the readout, $x \in \{0,1\}$, and $F : \{0,1\} \times \{0,1\}^2 \to \{0,1\}$. For each constant input $u$ write $g_u = F(\cdot, u)$, a self-map of $\{0,1\}$ (well defined because the inputs are source nodes held constant on a window, H1). Name $z = g_{(0,0)}$, $a = g_{(0,1)}$, $b = g_{(1,0)}$, $c = g_{(1,1)}$. The 256 tables $F$ are exactly the quadruples $(z,a,b,c)$ of self-maps.

**Step 1 (the four maps).** A self-map of $\{0,1\}$ is one of $\mathbf 0$ (constant 0), $\mathbf 1$ (constant 1), $\mathrm{id}$, $\lnot$. For a map $g$, start $x_0$ and length $n \ge 1$, define the window readout $E(g, x_0, n) = \bigvee_{t=1}^{n} g^{t}(x_0)$ and the end state $S(g, x_0, n) = g^{n}(x_0)$. Directly:

| $g$ | $E(g,x_0,n)$ | $S(g,x_0,n)$ |
|---|---|---|
| $\mathbf 0$ | $0$ | $0$ |
| $\mathbf 1$ | $1$ | $1$ |
| $\mathrm{id}$ | $x_0$ | $x_0$ |
| $\lnot$ | $\lnot x_0$ if $n = 1$; $1$ if $n \ge 2$ (the trajectory is $\lnot x_0, x_0, \lnot x_0, \dots$) | $x_0 \oplus (n \bmod 2)$ |

Only the $\lnot$ row depends on $n$, and only through $[n = 1]$ (for $E$) and $n \bmod 2$ (for $S$). Equivalently, for every self-map $g$ of $\{0,1\}$, $g^3 = g$, so $g^{n+2} = g^n$ for $n \ge 1$, and for $n \ge 2$ the set $\{g^t(x_0) : 1 \le t \le n\}$ is $\{g(x_0), g^2(x_0)\}$.

**Step 2 (the rest state, H4).** $x^*$ is a fixed point of $z$. $\lnot$ has no fixed point, $\mathbf 0$ fixes only $0$, $\mathbf 1$ fixes only $1$, $\mathrm{id}$ fixes both. So $z \in \{\text{constant } x^*, \mathrm{id}\}$. The pass predicate quantifies over $x^*$ existentially (H4), so the analysis below runs over both values of $x^*$ allowed by $z$.

**Step 3 (the gap, H2 with $G \ge 1$).** Each of $\mathbf 0, \mathbf 1, \mathrm{id}$ is idempotent, so $z^G = z$ for every $G \ge 1$. Hence the state entering the test is $y_v = z(S(g_v, x^*, W))$, which is $S(g_v, x^*, W)$ if $z = \mathrm{id}$ and $x^*$ if $z$ is the constant $x^*$, for every $G \ge 1$. This proves that the pass predicate does not depend on $G \ge 1$.

**Step 4 (the S1 reduction).** By Steps 1 and 3, every quantity in the pass predicate, the pretest readout $E(a, x^*, W)$, the unconditioned readout $E(b, x^*, W)$, and the three test readouts $E(a, y_v, W)$ with $y_v = z(S(g_v, x^*, W))$, depends on $(W, G)$ only through $[W = 1]$ and $W \bmod 2$, that is, through the class of $W$ among $\{1\}$, odd $W \ge 3$, even $W \ge 2$. So $(F, r)$ passes at $(W, G)$ iff it passes at $(\bar W, 1)$, where $\bar W = 1, 3, 2$ for the three classes respectively.

**Step 5 (the conditions).** Associative conditioning at $(W, G, W)$ from $x^*$ is:

1. pretest: $E(a, x^*, W) = 0$;
2. unconditioned: $E(b, x^*, W) = 1$;
3. paired: $E(a, y_{(1,1)}, W) = 1$;
4. unpaired: $E(a, y_{(1,0)}, W) = 0$ and $E(a, y_{(0,1)}, W) = 0$.

Conditions 1 and 3 together say that $E(a, \cdot, W)$ takes the value 0 at $x^*$ and 1 at $y_{(1,1)}$, so it is not constant; by the table, $a \notin \{\mathbf 0, \mathbf 1\}$, and $a = \lnot$ with $W \ge 2$ is excluded too ($E = 1$ everywhere). Two cases remain.

*Case A: $a = \mathrm{id}$.* Then $E(a, y, W) = y$, and condition 1 forces $x^* = 0$. Condition 3 asks $y_{(1,1)} = 1$. If $z = \mathbf 0$ (the constant $x^*$), every $y_v = 0$ and condition 3 fails; so $z = \mathrm{id}$ and $y_v = S(g_v, 0, W)$. Condition 2 asks $E(b, 0, W) = 1$ and condition 4 asks $S(b, 0, W) = 0$ (the $(0,1)$ half of condition 4 holds automatically: $y_{(0,1)} = S(\mathrm{id}, 0, W) = 0$). By the table: $b = \mathbf 0$ and $b = \mathrm{id}$ give $E = 0$; $b = \mathbf 1$ gives $S = 1$; $b = \lnot$ gives $E = 1$ and $S = W \bmod 2$. So condition 2 and condition 4 hold together iff $b = \lnot$ and $W$ is even. Finally condition 3 asks $S(c, 0, W) = 1$, which at even $W$ holds iff $c = \mathbf 1$ ($S(\lnot, 0, W) = 0$ at even $W$).

*Case B: $a = \lnot$ and $W = 1$.* Then $E(a, y, 1) = \lnot y$, condition 1 forces $x^* = 1$, so $z \in \{\mathbf 1, \mathrm{id}\}$. Condition 4 for $(0,1)$ asks $y_{(0,1)} = 1$, with $S(\lnot, 1, 1) = 0$: if $z = \mathrm{id}$ then $y_{(0,1)} = 0$, failing; so $z = \mathbf 1$. But then $y_{(1,1)} = 1$ and condition 3 asks $\lnot 1 = 1$, failing. No table passes in Case B.

**Conclusion of (a).** $(F, x^*)$ passes at $(W, G)$ with $G \ge 1$ iff $W$ is even, $x^* = 0$, and $(z, a, b, c) = (\mathrm{id}, \mathrm{id}, \lnot, \mathbf 1)$, which is the table $x' = (x \oplus u_1) \lor (x \land u_2)$ of MD_0097 (at $u = (0,0)$: $x$; $(0,1)$: $x$; $(1,0)$: $\lnot x$; $(1,1)$: $\lnot x \lor x = 1$). Hence:

- (i) no $(F, r)$ with $k = 1$ passes at any $(W, G)$ with $W$ odd and $G \ge 1$;
- (ii) for any $W, G \ge 1$ one of $W, W+1$ is odd, so by (i) no $(F, r)$ passes at both $(W, G)$ and $(W + 1, G)$. Concretely, passing at $(W, G)$ forces $W$ even, and then $W + 1$ is odd and fails with the same $G$.

**Enumeration check (not the proof).** A scratch script (not kept) ran all 256 tables, both rest states allowed by $z$, $W \in 1..12$, $G \in 1..9$ and compared the pass predicate with the characterization above (pass iff $W$ even, $x^* = 0$, $(z,a,b,c) = (\mathrm{id},\mathrm{id},\lnot,\mathbf 1)$): it agreed in all 27648 cases. At $G = 0$ the characterization fails (the table $(\mathbf 0, \mathrm{id}, \lnot, \mathbf 1)$, $x^* = 0$, also passes at even $W$, since without a gap update $z = \mathbf 0$ does not reset the trained state), but no table passes at odd $W$ there either.

## Part (b): $k = 2$

State $(M, R)$, readout $R$, update $M_{t} = M_{t-1} \lor (u_1 \land u_2)$, $R_{t} = u_1 \lor (u_2 \land M_{t-1})$, both computed from the previous state (H1, synchronous). Two invariants, each immediate from the update rule: (I1) under an input with $u_1 \land u_2 = 0$, $M_t = M_{t-1}$, so $M$ is constant on the window; under $(1,1)$, $M_t = 1$ for every $t \ge 1$. (I2) For $t \ge 1$, $R_t$ depends only on the input and $M_{t-1}$: $R_t = 1$ under $(1,0)$ and $(1,1)$; $R_t = M_{t-1}$ under $(0,1)$; $R_t = 0$ under $(0,0)$.

**Rest state (H4).** Under $(0,0)$: $M' = M$, $R' = 0$, so $(0,0) \mapsto (0,0)$ and $x^* = (0,0)$ is a fixed point.

**The five runs, for arbitrary $W \ge 1$, $G \ge 1$ (H2).** Readout evaluated at steps $t = 1, \dots, n$ of each window (H3).

1. *Pretest*, $(0,1)$ for $W$ from $(0,0)$: by I1 $M_t = 0$ for all $t$; by I2 $R_t = M_{t-1} = 0$ for $t = 1, \dots, W$. Does not evoke.
2. *Unconditioned*, $(1,0)$ for $W$ from $(0,0)$: by I2 $R_1 = 1$, and step 1 lies in the window since $W \ge 1$. Evokes.
3. *Paired*, $(1,1)$ for $W$: by I1 and I2, $(M_t, R_t) = (1,1)$ for $t = 1, \dots, W$; end state $(1,1)$. Gap $(0,0)$ for $G$: $M$ stays $1$ (I1), $R_t = 0$ for $t \ge 1$ (I2); end state $(1,0)$ for every $G \ge 1$. Test $(0,1)$: $R_1 = M_0 = 1$ (I2, $M_0$ being the gap's end value $1$). Evokes at step 1 of the test.
4. *Unpaired, $(1,0)$*, for $W$: $M$ stays $0$ (I1), $R_t = 1$; end state $(0,1)$. Gap: $M = 0$, $R_t = 0$ for $t \ge 1$; end state $(0,0)$. Test $(0,1)$: $M$ stays $0$, $R_t = M_{t-1} = 0$ for $t = 1, \dots, W$. Does not evoke.
5. *Unpaired, $(0,1)$*, for $W$: $M$ stays $0$, $R_t = M_{t-1} = 0$; end state $(0,0)$. Gap: stays $(0,0)$. Test: as the pretest, $R_t = 0$. Does not evoke.

All four conditions of associative conditioning hold at $(W, G, W)$ from $x^* = (0,0)$, for every $W \ge 1$ and $G \ge 1$; so the witness passes at every such $(W, G)$. (The test readouts in runs 3 to 5 depend only on the value of $M$ at the test's start, which is $1$ iff the training window contained a step with $u_1 \land u_2 = 1$; the gap value of $R$ is never read by the test, since $R_1$ under $(0,1)$ reads only $M_0$.) The enumeration check above also ran the witness at all $(W, G) \in 1..40 \times 1..40$: it passes at every point.

## Corollary: four nodes

Call a network robust if it passes at some odd $W$ for some $G \ge 1$, or at $(W, G)$ and $(W+1, G)$ for some $W, G \ge 1$. A network with $k = 0$ internal nodes has no readout node, so the pass predicate is not defined for it. By (a)(i) no $k = 1$ network passes at an odd window, and by (a)(ii) none passes at two consecutive windows with the same gap; so no $k = 1$ network is robust. By (b) the $k = 2$ witness passes at every $(W, G)$, in particular at $(1, 1)$ (odd window) and at $(1,1)$ and $(2,1)$; so it is robust. The minimal number of internal nodes of a robust network is therefore $2$, and counting the two input nodes the minimal robust network has $2 + 2 = 4$ nodes.

## Where the hypotheses are used

- **H1** (synchronous update, inputs as source nodes): Part (a) Setup, so that $F(\cdot, u)$ is a single self-map $g_u$ iterated on each window; Part (b), so that $R_t$ reads $M_{t-1}$, not $M_t$ (run 3's test readout $R_1 = M_0$, run 5's $R_t = M_{t-1} = 0$).
- **H2** ($W, G$ counted in updates, $W, G \ge 1$): $W \ge 1$ makes every window nonempty (run 2 evokes at step 1; Step 1's table is for $n \ge 1$); $G \ge 1$ is Step 3 ($z^G = z$, so the constant gap map resets the state). Without $G \ge 1$ the characterization in (a) changes (see the enumeration check); (a)(i) and (b) remain true at $G = 0$ but that is not claimed.
- **H3** (readout on the states after each update): the definition of $E$ in Step 1 (steps $1..n$, excluding $x_0$), which gives the $\lnot$ row its $[n = 1]$ dependence and Case B; Part (b) runs 1 to 5.
- **H4** (rest state a fixed point of $z$, existential): Step 2, which excludes $z = \lnot$ and is what makes $z$ idempotent in Step 3; the case analysis covers both admissible $x^*$; Part (b)'s rest-state check.

## Formalization blockers

None. Both parts are finite and formalizable today in Lean 4 over `Bool` with `Function.iterate` (`f^[n]`), with no ODE content. Suggested shape: define the window readout `E g x n := ∃ t ∈ Finset.Icc 1 n, g^[t] x = true` (or a `List.range`/`foldl` OR, decidable), the end state `g^[n] x`, and `passes F W G` as the existential over `x* : Bool` with `F x* false false = x*` of the four conditions, all decidable.

(a) The Lean prover formalizes exactly the reduction of Steps 1, 3 and 4:
- `∀ g : Bool → Bool, ∀ x, g (g (g x)) = g x` (by `decide`, 4 maps times 2 points), hence `g^[n+2] x = g^[n] x` for `n ≥ 1` (induction with `Function.iterate_succ_apply'` / `Function.iterate_add_apply`), hence `E g x n ↔ E g x (red n)` and `g^[n] x = g^[red n] x` with `red 1 = 1`, `red n = 3` for odd `n ≥ 3`, `red n = 2` for even `n ≥ 2`;
- `∀ z : Bool → Bool, (∃ x, z x = x) → z ∘ z = z` (by `decide`), hence `z^[G] = z` for `G ≥ 1`;
- together, `passes F W G ↔ passes F (red W) 1` for `W, G ≥ 1`.

The finite set that suffices: for clause (i), $(W, G) \in \{(1,1), (3,1)\}$, since every odd $W$ reduces to $\bar W \in \{1, 3\}$ and every $G \ge 1$ to $1$; the `decide` is `∀ F : Bool → Bool → Bool → Bool, ¬ passes F 1 1 ∧ ¬ passes F 3 1` over the 256 functions (the `Fintype` instance for the function type is `Pi.instFintype`; if `decide` is slow on the curried function type, quantify over the 8-bit table `Fin 8 → Bool` or over the quadruple `(z,a,b,c)` of `Bool → Bool`). Clause (ii) needs no further `decide`: it follows from (i) because one of $W, W+1$ is odd (`Nat.even_or_odd`). The S1 note's set $W \in \{1,2,3,4\}$, $G = 1$ is more than enough; $W = 2$ is needed only to state the full characterization (one passing table at even $W$), which the entry does not claim.

(b) Induction, not `decide`: lemmas for the window under each constant input (by induction on $n$: under $(0,1)$ from $(0, R)$ the state after $t \ge 1$ steps is $(0,0)$; under $(1,1)$ it is $(1,1)$; under $(1,0)$ from $(0,R)$ it is $(0,1)$; under $(0,0)$ from $(M,R)$ it is $(M,0)$; under $(0,1)$ from $(1,0)$ step 1 has $R = 1$), then the five runs follow by rewriting, for all $W, G \ge 1$.
