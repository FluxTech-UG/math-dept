## Statement

Assume the common setting H1 and an embedded error estimate E(y, h, theta) in R^d, C^{p+1} in all arguments, with c_E h^{p+1} <= ||E(y, h, theta)|| <= C_E h^{p+1} on K_delta for some 0 < c_E <= C_E (a nondegenerate estimate); || . || is the Euclidean norm. Fix phi : (0, inf) -> [phi_min, phi_max], 0 < phi_min < 1 < phi_max, smooth and nondecreasing, with the step-size stability bound sup over x > 0 of (p+1) x phi'(x)/phi(x) <= 2 - gamma for some gamma > 0, with phi(x) <= rho for all x < 1 for some rho < 1 (a rejection shrinks the trial step by a factor bounded away from 1, so every step terminates), a tolerance tau > 0 and an initial trial step h_init(tau) independent of theta. The controller: at t_n with trial step h, set h := min(h, T - t_n) (clip), compute eps = ||E(y_n, h, theta)||; accept iff eps <= tau. If rejected, h := h phi(tau/eps) and retry. If accepted, y_{n+1} = Psi_h(y_n, theta), t_{n+1} = t_n + h, next trial step h phi(tau/eps). Stop when t_n = T. This defines a grid h(theta, tau). The decision pattern is the finite sequence of accept/reject outcomes, clip events, and N. Fix kappa > 0. Let U be an open subset of Theta on which the decision pattern is constant and every eps evaluated at an unclipped trial step satisfies eps >= kappa tau (a clipped final step's eps only decides acceptance and feeds no later step). Claims: (a) theta -> y_N(theta; h(theta, tau)) is C^1 on U. (b) There are tau0 > 0 and C', depending only on the derivative bounds of f and E on K_delta, on T, the tableau, phi, gamma, c_E, kappa and the C^1 norm of y0, and not on tau or U, such that for tau <= tau0, theta in U and H <= H0 (H0 as in MD_0019 clause (ii)), ||d_theta [y_N(theta; h(theta, tau))] - d_theta y_N(theta; h)|_{h = h(theta, tau)}|| <= C' H^p, H the largest accepted step. (c) Consequently both derivatives differ from S(T; theta) by at most a constant (same dependence) times H^p.

## Hypotheses

- **H1.** Integers d, m, p >= 1. Theta is an open subset of R^m. f : R^d x Theta -> R^d is C^{p+1}; y0 : Theta -> R^d is C^1. An explicit Runge-Kutta method is given by a Butcher tableau (A, b, c) with A strictly lower triangular, of classical order p, with coefficients independent of theta; Psi_h(y, theta) denotes one step of size h. A grid is 0 = t_0 < t_1 < ... < t_N = T with steps h_n = t_{n+1} - t_n and H = max_n h_n. y_N(theta; h) = Psi_{h_{N-1}} o ... o Psi_{h_0} (y0(theta), theta). y(t; theta) is the exact solution of y' = f(y, theta), y(0) = y0(theta), assumed to exist on [0, T]. S(t; theta) solves S' = f_y(y(t; theta), theta) S + f_theta(y(t; theta), theta), S(0) = d_theta y0(theta). Norms on R^d and on d x m matrices are fixed (any choice; constants depend on it). For theta in Theta and delta > 0, K_delta is the closed delta-neighbourhood of the trajectory {y(t; theta) : 0 <= t <= T}.
- **H2.** The embedded error estimate, the controller and the decision pattern as defined in the Statement.
- **H3.** The step-size stability bound sup_x (p+1) x phi'(x)/phi(x) <= 2 - gamma with gamma > 0, and the nondegenerate estimate ||E|| >= c_E h^{p+1}, both as stated in the Statement.

## Why it was raised

The repaired statement of MD_0020, whose claim (b) fails numerically for an expanding accepted-step map, for the same application in 1DSim3 (MDR:2026-10-16-adaptive-grid-gradient#C2 line).

## Current notes

Refuted on 2026-10-17 by the exact witness listed under evidence (`python -m mdept.refute MD_0027` prints ok, exact): d = m = p = 1, f = -theta y, y0 = 1, Euler, T = 2, kappa = 1/4, phi(x) = (1 + 3v)/(3 + v) with v = sqrt(x/2) (slope bound met with gamma = 3/2), h_init = sqrt(tau)/2, and the estimate E(y, h, theta) = h^2 (2 + a(h) Q((theta - 1)/h)) with a(h) = sqrt(h)/(4 (1 + sqrt(h))) and Q(s) = s chi(s) for a smooth cutoff chi: E is C^2 jointly up to h = 0 and nondegenerate (3/2 h^2 <= E <= 5/2 h^2), but d log E/d theta ~ h^{-1/2}/8 is unbounded. At theta = 1 with tau = 64/j^4 (j odd) every unclipped step accepts at eps = tau/2 with h = 4/j^2 and the run ends in a clip; the controller term satisfies |R|/H >= (j - 3)/672 -> infinity, against the claimed C' H^p = C' H, so no tau0, C', H0 satisfy clause (b), and the full half of (c) falls with it. Clause (a) stands by the MD_0020 proof. An adversarial review by a fresh context on 2026-10-17 accepted the witness: the Statement constrains E only by C^{p+1} regularity and two-sided h^{p+1} bounds, which give d_theta E = o(h^p) and not O(h^{p+1}); a real embedded pair has E = h^{p+1} e(y, h, theta) with e smooth, which the text does not require. Revises MD_0020 by the step-size stability bound and the nondegenerate estimate; the review of MD_0020's witness found that the nondegenerate estimate alone does not exclude it while the slope bound does (keeping the accepted-step map's slope in [-1 + gamma, 1]), and this witness shows the pair still leaves the forcing d log E/d theta free. Repair for a successor: E = h^{p+1} e(y, h, theta) with e C^1 on K_delta x [0, h_max] x Theta and |e| >= c_E (equivalently ||d_y E|| + ||d_theta E|| <= C_E h^{p+1} on K_delta); the reviewer's sketch has R = O(H^p) under it, with the retry count per step (from eps >= kappa tau and rho < 1) the point a proof must still check. The parenthetical "so every step terminates" in the controller text is a comment, not a hypothesis, and the MD_0024 review found it false as a claim about reaching T. The narrowed successor is MD_0030, which revises this one.
