## Statement

$\text{With } \Omega, \omega \text{ fixed, let } F(D) := \langle h_D \rangle \text{ where } i\omega h_D = D\nabla_\perp^2 h_D, \ h_D = 1 \text{ on } \partial\Omega, \text{ so } f_v = F(\nu), f_\kappa = F(\alpha). \text{ Then } F \text{ is holomorphic in } D \text{ on a neighbourhood of } (0,\infty), \text{ and as } \nu \to \alpha \text{ the bracket extends continuously with } \lim_{\mathrm{Pr}\to 1} \tfrac{f_\kappa - f_v}{(1 - f_v)(1 - \mathrm{Pr})} = \tfrac{\left[\,dF/d\log D\,\right]_{D=\alpha}}{1 - F(\alpha)} = -\left[\tfrac{d\log(1 - F)}{d\log D}\right]_{D=\alpha}, \text{ and } g_{v\kappa}\big|_{\mathrm{Pr}=1} = 1 - F(\alpha) + \alpha F'(\alpha). \text{ The limit is finite. For parallel plates of half-gap } y_0, \ F(z) = \tanh z / z \text{ with } z = y_0\sqrt{i\omega/\alpha}, \text{ and the limit is } \tfrac{1}{2}\,\tfrac{F(z) - \operatorname{sech}^2 z}{1 - F(z)}.$

## Hypotheses

H1 the single-geometry setting of C1, so that $f_v$ and $f_\kappa$ are one function of the diffusivity evaluated twice; H2 $\omega > 0$, which gives $F(\alpha) \neq 1$ and keeps the denominator away from zero.

Raised by 1DSim3 through C2 of MDR:2026-09-16-two-parameter-gain.

## Current notes

Refuted as printed: the value clause carries $+\alpha F'(\alpha)$ and the truth is $-\alpha F'(\alpha)$. `counterexamples/MD_0012_sign_of_derivative_term.py` certifies it numerically at the disc against MD_0011's modal form; the four other clauses are proved in `proofs/MD_0012.md` and carried by MD_0016, which supersedes this entry.
