## Statement

**Protocol (common to this request).** A network is $\dot x = f(x,u)$ on a forward-invariant $X \subseteq \mathbb{R}^n$ with input $u \in \{0,1\}^2$ piecewise constant, readout $\rho : X \to \mathbb{R}$ and threshold $\theta$; or, in the Boolean class, $x_{t+1} = F(x_t, u_t)$ with $x \in \{0,1\}^k$, synchronous update, the two inputs as source nodes, readout one internal node $r$. A rest state $x^*$ is an equilibrium (fixed point) of the input-free dynamics $u = (0,0)$. For a training input $v \in \{0,1\}^2$, window lengths $T_1, T_3$ and gap $T_2$, the **test readout** $\phi_v(T_2)$ is the readout trajectory on the test window of the run that starts at $x^*$, applies $v$ for $T_1$, then $(0,0)$ for $T_2$, then $(0,1)$ for $T_3$. The **pretest readout** $\phi_0$ is the readout trajectory under $(0,1)$ for $T_3$ from $x^*$. A readout trajectory **evokes** when it exceeds $\theta$ (equals 1) at some time of its window. **Associative conditioning** at $(T_1,T_2,T_3)$ holds when: $\phi_0$ does not evoke; the readout under $(1,0)$ for $T_3$ from $x^*$ evokes; $\phi_{(1,1)}(T_2)$ evokes; and neither $\phi_{(1,0)}(T_2)$ nor $\phi_{(0,1)}(T_2)$ evokes. It is **persistent** when it holds for all sufficiently large $T_2$.

**Statement.** In the Boolean class with $k$ internal nodes, inputs as source nodes, and readout an internal node $r$, say $(F, r)$ **passes at** $(W, G)$ when there is a fixed point $x^*$ of $F(\cdot,(0,0))$ such that associative conditioning holds at $(T_1,T_2,T_3) = (W, G, W)$ from $x^*$. Then: (a) for $k \le 1$, no $(F, r)$ passes at any $(W,G)$ with $W \ge 1$, $G \ge 1$; (b) for $k = 2$, there is $(F, r)$ that passes at every $(W, G)$ with $W \ge 1$, $G \ge 1$; a candidate witness is $M_{t+1} = M_t \lor (u_1 \land u_2)$, $R_{t+1} = u_1 \lor (u_2 \land M_t)$ with $r = R$ and $x^* = (0,0)$. Counting the two input nodes, the minimal passing network has four nodes.

## Hypotheses

- **H1.** Synchronous update; inputs are source nodes (their values are set by the protocol, not by $F$).
- **H2.** Windows and gap are measured in update steps; $W \ge 1$ and $G \ge 1$.
- **H3.** "Evokes" means $x_r = 1$ at some step of the window, the readout being evaluated on the states produced during the window (after each update).
- **H4.** The rest state is a fixed point of $F(\cdot,(0,0))$, existentially quantified in the pass predicate.

## Current notes

Part (a) is false as stated: the one-node network x' = (x XOR u1) OR (x AND u2), readout x, rest 0, passes at every even training window (counterexamples/MD_0097_one_node_even_window.py, exact under python -m mdept.refute). It passes at no odd window and at no two consecutive windows. Part (b) holds on the tested range. A prover context that did not write the witness re-ran python -m mdept.refute MD_0097 (ok, exact) and checked the four runs by hand; the lead then set refuted. MD_0101 restates the proposition for odd windows.
