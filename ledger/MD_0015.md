## Statement

$\text{Let } \Omega \subset \mathbb{R}^3 \text{ be a pore space with smooth walls } \partial\Omega \text{ and let } v \text{ be the leading-order inviscid (potential) velocity field in it. For a weight } w \geq 0 \text{ define } 2/\Lambda_w := \int_{\partial\Omega} w \, dS \big/ \int_\Omega w \, dV, \text{ so that } \Lambda_{w = |v|^2} = \Lambda \text{ and } \Lambda_{w = 1} = \Lambda'. \text{ Then in the thin-layer regime } \delta_\alpha = \sqrt{2\alpha/\omega} \ll \text{pore size}, \ g_{v\kappa} = 1 - (1 - i)\,\sqrt{\tfrac{2\alpha}{\omega}}\;\tfrac{1 + \sqrt{\mathrm{Pr}} + \mathrm{Pr}}{(1 + \sqrt{\mathrm{Pr}})\,\Lambda''} + O(\omega^{-1}), \text{ where } \Lambda'' = \Lambda_{w = |v|}, \text{ the cross term being linear rather than quadratic in } v; \text{ and } \Lambda'' \text{ lies between } \Lambda \text{ and } \Lambda', \text{ with } \Lambda'' = \Lambda = \Lambda' = 2V/S \text{ whenever } |v| \text{ is constant on } \Omega, \text{ as it is for a straight uniform pore.}$

## Hypotheses

H1 walls smooth enough that the oscillatory boundary layer is locally one-dimensional and the layers are thin against every radius of curvature; H2 $|v|$ bounded above and below away from zero on $\Omega$, so all three weighted lengths are finite and positive; H3 $\mathrm{Pr} > 0$, including $\mathrm{Pr} = 1$, where the coefficient is $3/2$ and finite.

## Current notes

Refuted (numeric): each of the Statement's two contentful clauses is false, with its own verifying witness, and an adversarial review by a context that wrote neither witness accepted both. The single-length clause fails on `counterexamples/MD_0015_single_length_high_frequency.py`, a slowly varying axisymmetric duct $R(x) = 1 + 0.6\cos(2\pi x/L)$ with $\Lambda = 0.54237$, $\Lambda'' = 0.80000$, $\Lambda' = 1.18000$, on which the printed coefficient misses the normalization-free deficit ratio by 10 to 46 percent across $\mathrm{Pr}$ while the two-length form of MD_0018 matches to parts in $10^4$; the verdict holds in the slowly varying limit, under an argued interchange of the $L \to \infty$ and $\omega \to \infty$ limits. Betweenness $\Lambda \le \Lambda'' \le \Lambda'$ fails in both directions on `counterexamples/MD_0015_shape_varying_duct.py`, a smooth periodic duct whose area and aspect-ratio profiles vary independently, with the potential problem solved by finite elements: $\Lambda' = 0.2588096$, $\Lambda = 0.2449689$, $\Lambda'' = 0.2311194$, a full interval width below the pair, and a second pore 3.24 percent above both. The same profiles on an elliptic section, all walls smooth, put $\Lambda''$ 9.2 percent below both other lengths in a converged three-dimensional solve, so the rectangular section's edges are not the loophole. Betweenness does hold on the slowly varying classes, including the axisymmetric one by Chebyshev's sum inequality. What survives is the Prandtl coefficient, the linearity of the cross term, and the $2V/S$ reduction, all carried by MD_0018. The clean replacement for betweenness is that it holds if and only if $\operatorname{Cov}_p(r, \log|\tilde v|) \ge 0$ across $p \in [0,2]$, with $r$ the local wall-to-volume ratio. The attempts and both reviews are in `triage/MD_0015.md`.
