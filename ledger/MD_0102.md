## Statement

**Protocol (Boolean class).** A network is $x_{t+1} = F(x_t, u_t)$ with $x \in \{0,1\}^k$, synchronous update, the two inputs $u \in \{0,1\}^2$ as source nodes set by the protocol, readout one internal node $r$. A rest state $x^*$ is a fixed point of $F(\cdot,(0,0))$. For a training input $v \in \{0,1\}^2$, window lengths $T_1, T_3$ and gap $T_2$, the **test readout** $\phi_v(T_2)$ is the sequence of values of $x_r$ on the $T_3$ states produced during the test window of the run that starts at $x^*$, applies $v$ for $T_1$ steps, then $(0,0)$ for $T_2$ steps, then $(0,1)$ for $T_3$ steps; the **pretest readout** $\phi_0$ is the same sequence under $(0,1)$ for $T_3$ steps from $x^*$. A readout **evokes** when it equals 1 at some step of its window. **Associative conditioning** at $(T_1,T_2,T_3)$ holds when $\phi_0$ does not evoke, the readout under $(1,0)$ for $T_3$ steps from $x^*$ evokes, $\phi_{(1,1)}(T_2)$ evokes, and neither $\phi_{(1,0)}(T_2)$ nor $\phi_{(0,1)}(T_2)$ evokes. It is **persistent** when it holds for all sufficiently large $T_2$.

**Statement.** If every trajectory of $F(\cdot,(0,0))$ reaches a single fixed point $x^*$ within $m$ steps, then for every training input $v$, every $T_1, T_3$ and every $T_2 \ge m$, $\phi_v(T_2) = \phi_0$ exactly; hence associative conditioning fails at every $(T_1, T_2, T_3)$ with $T_2 \ge m$, and none is persistent. The argument uses nothing about the state space beyond the map: the same holds for any state set and any readout function on it, $\{0,1\}^k$ with a readout node being the instance the application uses.

## Hypotheses

- **H1.** Synchronous update; the inputs are source nodes whose values the protocol sets.
- **H2.** $x^*$ is a fixed point of $F(\cdot,(0,0))$ and $F(\cdot,(0,0))^{m}(x) = x^*$ for every state $x$ (every trajectory is at $x^*$ from step $m$ on; with the fixed point this is "within $m$ steps").
- **H3.** The readout is evaluated on the states produced during a window, after each update, the same convention for test and pretest.

## In plain words

Take a discrete-time network that, with its inputs switched off, always falls back to one and the same rest state, and gets there within m steps from any state. Whatever training it received, a quiet gap of m steps or more returns it to that rest state, so the test that follows is exactly the run an untrained network would produce. The entry proves this: after a gap of at least m steps the test readout equals the pretest readout, for every training input and every window length. Nothing about Boolean states is used; the argument holds for any state set and any readout.

Associative conditioning needs the readout after paired training to differ from the untrained one, so it fails at every gap of m or more and is never persistent. For the consumer, a Boolean network meant to learn and keep an association must, with its inputs off, either have more than one rest state or have trajectories that never reach the rest state (a cycle, for instance). This is the Boolean form of MD_0096, and the proof is machine-checked in Lean.
