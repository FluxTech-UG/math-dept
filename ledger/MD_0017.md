## Statement

$$
\begin{aligned}
&\text{Let } \Omega \subset \mathbb{R}^2 \text{ be a bounded Lipschitz domain, } \Delta\Phi = -1 \text{ and } \Delta\Psi = -\Phi \text{ on } \Omega \text{ with } \Phi, \Psi \in H^1_0(\Omega). \\
&\text{Then } \langle\Psi\rangle = \langle\Phi^2\rangle > 0, \text{ and with } \nu, \alpha > 0 \text{ fixed,} \\[4pt]
&\qquad g_{v\kappa}(\omega) \;=\; -\,\frac{\omega^2}{\nu\alpha}\,\langle\Psi\rangle \;+\; O(\omega^3)
\qquad (\omega \to 0), \\[4pt]
&\text{the } O(\omega) \text{ terms cancelling identically. Set } \chi(\Omega) := \langle\Psi\rangle/\langle\Phi\rangle^2. \text{ Then} \\[4pt]
&\qquad \chi(\text{disc}) = \tfrac{4}{3} \ \text{ exactly}, \qquad
\chi(Q_a) = 1.3784187\ldots \neq \tfrac{4}{3} \ \text{ for the square } Q_a = (-a,a)^2, \\[4pt]
&\text{whose moments are the convergent sums over ODD } m, n \geq 1 \\[4pt]
&\qquad \langle\Phi\rangle_{Q_a} = \frac{256\,a^2}{\pi^6}\sum_{m,n \text{ odd}} \frac{1}{m^2 n^2 (m^2+n^2)} = 0.140577015\ldots\,a^2
= \frac{a^2}{3} - \frac{64\,a^2}{\pi^5}\sum_{m \text{ odd}} \frac{\tanh(m\pi/2)}{m^5}, \\
&\qquad \langle\Psi\rangle_{Q_a} = \frac{1024\,a^4}{\pi^8}\sum_{m,n \text{ odd}} \frac{1}{m^2 n^2 (m^2+n^2)^2} = 0.0272401684\ldots\,a^4 . \\[4pt]
&\text{Consequently the disc of radius } R \text{ with } R^2 = 8\langle\Phi\rangle_{Q_a} \text{ and } Q_a \text{ share } \langle\Phi_v\rangle = \langle\Phi_\kappa\rangle \\
&\text{while their } \langle\Psi\rangle \text{ differ by the factor } \chi(Q_a)/\chi(\text{disc}) = 1.033814\ldots, \text{ that is by } 3.38 \text{ percent}: \\
&\text{so } \langle\Psi\rangle \text{ is not a function of } (\langle\Phi_v\rangle, \langle\Phi_\kappa\rangle) \text{ alone. Both witness domains are bounded and Lipschitz in } \mathbb{R}^2 .
\end{aligned}
$$

This revises MD_0014, whose witness pair uses the slab $\{|y| < y_0\}$, which is unbounded in
$\mathbb{R}^2$ and so falls outside its own H2. Every other clause of MD_0014 is unchanged and is
proved in `proofs/MD_0014.md`; this entry replaces only the witness, at the cost of a smaller gap
(3.38 percent here against 11.1 percent there).

## Hypotheses

- **H1.** One and the same bounded Lipschitz $\Omega \subset \mathbb{R}^2$ carries both channel
  problems, so $\Phi_v = \Phi_\kappa = \Phi$ and $\langle\Psi\rangle = \langle\Phi_v\Phi_\kappa\rangle
  = \langle\Phi^2\rangle$.
- **H2.** $\Omega$ bounded with boundary regular enough that $\Phi, \Psi \in H^1_0(\Omega)\cap C(\bar\Omega)$
  and the Dirichlet spectrum is discrete with $\sum_n w_n/\mu_n^2 < \infty$, where $w_n$ are the squared
  means of the normalized eigenfunctions. The open disc and the open square both satisfy it, the square
  being Lipschitz although not smooth.
- **H3.** $\nu, \alpha > 0$ fixed while $\omega \to 0$, so the expansion is in $\omega$ at fixed
  diffusivities and not a joint limit.
- **H4.** $g_{v\kappa}$ is the averaged solution of the cross problem of MD_0011, so that MD_0011's
  identity $g_{v\kappa} = ((1-f_\kappa) - \mathrm{Pr}(1-f_v))/(1-\mathrm{Pr})$ is available.

## In plain words

The special case is slow oscillation, frequency going to zero. Two Poisson problems on the cross-section govern it: the profile of steady viscous flow, which solves the Poisson equation with a constant source and vanishes on the wall, and a second potential whose source is that profile. The result says the cross term starts at second order in frequency, with the average of the squared flow profile as its coefficient, and the first-order terms cancel exactly. The ratio of that average to the squared mean of the profile is a pure shape number: exactly 4/3 for a disc and about 1.378 for a square. So a disc and a square sized to share the same mean profile, and hence the same static viscous and thermal permeabilities, differ in the low-frequency gain coefficient by 3.38 percent. Both shapes are bounded, which repairs the witness of MD_0014.

For the application that raised it, the low-frequency gain is not a function of the two static permeabilities alone: a closure needs this shape number as an independent input, computed from the cross-section. In general only that the shape number exceeds one is proved; no larger lower bound is known for any class of shapes.
