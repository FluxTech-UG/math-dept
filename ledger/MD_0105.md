## Statement

**Setting.** $C$ is a finite set of configurations, $|C| = N \ge 1$, and $c_0 \in C$. $U$ is a finite nonempty input alphabet and $\{M_u\}_{u \in U}$ a family of self-maps of $C$. For $k \ge 0$ the set reachable in exactly $k$ turns is $R_k(c_0) = \{ M_{u_k} \circ \cdots \circ M_{u_1}(c_0) : (u_1, \dots, u_k) \in U^k \}$ (so $R_0(c_0) = \{c_0\}$).

**Statement.** (a) If $M_u \circ M_v = M_v \circ M_u$ for all $u, v \in U$, then $|R_k(c_0)| \le \binom{k + |U| - 1}{|U| - 1}$ for every $k \ge 0$, a bound that is a polynomial in $k$ of degree $|U| - 1$ and does not depend on $N$. (b) With no commutation assumption, $|R_k(c_0)| \le |U|^k$ for every $k \ge 0$. (c) For every finite nonempty $U$ and every $k \ge 0$ there are a finite set $C$ (necessarily with $N \ge |U|^k$), maps $\{M_u\}_{u \in U}$ and $c_0 \in C$ with $|R_k(c_0)| = |U|^k$ (by (a), such maps cannot all commute once $|U| \ge 2$ and $k \ge 2$).

## Hypotheses

- **H1.** $C$ finite and nonempty; $U$ finite and nonempty ($|U| \ge 1$, so the binomial in (a) is the ordinary one).
- **H2.** Pairwise commutation of the $M_u$, for (a) only.
- **H3.** The input is held fixed during one turn, so a $k$-turn run is a word of length exactly $k$ in the maps.

## In plain words

Start from one configuration of a finite set and at each turn apply one of several maps, one per input letter, so that k turns spell an input word of length k. If the maps commute, the order of the letters does not matter, only how many times each letter was used, so no more configurations are reachable in k turns than there are such letter counts. That number is a polynomial in k of degree one less than the number of letters, and it does not depend on how large the configuration set is: with two letters, at most k + 1 configurations are reachable in k turns. Without commutation the only bound is the number of words, the number of letters to the power k, and it is attained: maps that append each letter to a growing record reach a distinct configuration for every word.

For the consumer, commutation separates polynomial growth of the reachable set from exponential growth. With commuting maps a search over input sequences need only enumerate letter counts, not orderings; with noncommuting maps every ordering can lead somewhere new. The proof is machine-checked in Lean, and the polynomial bound is attained by maps that count each letter separately.
