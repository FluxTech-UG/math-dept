## Statement

**Protocol (Boolean class).** A network is $x_{t+1} = F(x_t, u_t)$ with $x \in \{0,1\}^k$, synchronous update, the two inputs $u \in \{0,1\}^2$ as source nodes set by the protocol, readout one internal node $r$. A rest state $x^*$ is a fixed point of $F(\cdot,(0,0))$. For a training input $v \in \{0,1\}^2$, window lengths $T_1, T_3$ and gap $T_2$, the **test readout** $\phi_v(T_2)$ is the sequence of values of $x_r$ on the $T_3$ states produced during the test window of the run that starts at $x^*$, applies $v$ for $T_1$ steps, then $(0,0)$ for $T_2$ steps, then $(0,1)$ for $T_3$ steps; the **pretest readout** $\phi_0$ is the same sequence under $(0,1)$ for $T_3$ steps from $x^*$. A readout **evokes** when it equals 1 at some step of its window. **Associative conditioning** at $(T_1,T_2,T_3)$ holds when $\phi_0$ does not evoke, the readout under $(1,0)$ for $T_3$ steps from $x^*$ evokes, $\phi_{(1,1)}(T_2)$ evokes, and neither $\phi_{(1,0)}(T_2)$ nor $\phi_{(0,1)}(T_2)$ evokes. It is **persistent** when it holds for all sufficiently large $T_2$.

**Statement.** Let the interaction graph on the internal nodes (an edge $j \to i$ when $F_i(\cdot,(0,0))$ depends essentially on $x_j$: changing $x_j$ changes $F_i$ for some value of the other coordinates) be acyclic, with depth $d$ the number of edges on its longest directed path (a node with no internal parents has depth 0); equivalently, let there be a depth function on the internal nodes, bounded by $d$, with every essential parent of a node strictly shallower than the node. Then $F(\cdot,(0,0))$ has a unique fixed point $x^*$, every trajectory under $(0,0)$ reaches it within $d + 1$ steps, and for every training input $v$, every $T_1, T_3$ and every $T_2 \ge d + 1$, $\phi_v(T_2) = \phi_0$ from any rest state; hence no associative conditioning at $(T_1, T_2, T_3)$ with $T_2 \ge d + 1$, and none persistent.

## Hypotheses

- **H1.** Synchronous update; the inputs are source nodes whose values the protocol sets.
- **H2.** The interaction graph on the internal nodes under input $(0,0)$ is acyclic with depth $d$, encoded as a depth function $\mathrm{depth} : \{1,\dots,k\} \to \mathbb{N}$ with $\mathrm{depth}(i) \le d$ for every $i$ and $F_i(x,(0,0)) = F_i(y,(0,0))$ whenever $x_j = y_j$ for every $j$ with $\mathrm{depth}(j) < \mathrm{depth}(i)$. The longest-path depth of an acyclic graph is such a function; the encoding constrains only the input-free slice of $F$, so it is implied by acyclicity of the full essential-dependence graph and the result is at least as strong as the graph form.
- **H3.** The readout is evaluated on the states produced during a window, after each update, the same convention for test and pretest. The rest state is any fixed point of $F(\cdot,(0,0))$ (there is exactly one).
